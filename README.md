# Zone Reminder

Release downloads for **Zone Reminder**, a small Windows tray app for Fortnite that reminds you at the storm zones you pick.

**[Download the latest ZoneReminder.exe](https://github.com/foxscc/ZoneReminder-releases/releases/latest/download/ZoneReminder.exe)**

- Single exe, no installer. It checks this page for new versions and updates itself.
- It only reads the log file Fortnite already writes. It doesn't touch the game or inject anything.
- The exe isn't code-signed, so Windows SmartScreen may show a warning the first time. Choose "More info", then "Run anyway", if you trust it.

Zone Reminder is an independent tool and is not affiliated with or endorsed by Epic Games.
